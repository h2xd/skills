# ADR issue

The tracker issue a decision record is opened under. Step 3 of
[`SKILL.md`](SKILL.md) fills it, per
[`../setup-tone/github-text.md`](../setup-tone/github-text.md).

Title: `ADR: <the problem and the chosen option>`. Label: `adr`.

```markdown
## Summary

- <The decision to make, in one line.>
- <Why it comes up now, in one line.>

## Problem

<One to three sentences, ending in a question.>

## Options

- <option 1>
- <option 2>

## Related

- <record or issue, and its bucket from step 2>
```
