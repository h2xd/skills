# Report format

The step 6 report of `h2xd:session-reflect`, one line per lesson, worst first:

```
🔴 <rule>: <a check that could not be proven to fail, or a fix that broke the build, and the next action>
🟡 <rule>: <filed as <issue URL>, shown as a draft for the user to copy, or routed to words with no check behind it>
🟢 <rule>: <level, what changed, the commit SHA>
⚪ <rule>: <dropped, with the reason>
```
