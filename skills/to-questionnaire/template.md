# Questionnaire template

Copy the block below into the questionnaire file. Replace every `<...>`. Delete
a section only where this file says it is optional.

```markdown
# <Title: the decision, in a few words>

**Purpose.** <The decision riding on these answers, in one or two sentences.>

**From** <the user>. **To** <the recipient>. **Round** <n>.

**How your answers will be used.** <Where they go: a decision record, an
issue, a design. Name it.>

## Context

<One paragraph for a reader who was not in the conversation. Give what they
need to answer well, and no more. Link the issue or page it came from.>

## How to answer

Tick one box per question. The first option is our recommendation, so ticking
it is enough when you agree. When none fits, tick "Something else" and write
your answer. "I don't know" is a useful answer. Tick it rather than skip the
question.

Reply by <deadline>. It takes about <n> minutes.

## <Theme, only when there are two or more themes>

### 1. <One question, one idea, ending in a question mark>

_Why this matters: <one line, only when the question could be misread or
invite a throwaway answer.>_

- [ ] **<Answer in 1 to 5 words>** (recommended). <What follows from it.>
- [ ] **<Answer>**. <What follows from it.>
- [ ] **I don't know.** <Who might know, if you can say.>
- [ ] **Something else:**

> Notes:

### 2. <A fact only the recipient has, where no options fit>

Our best guess: <the guess, and what it rests on>. Correct it if it is wrong.

> Answer:

## Anything else?

Is there something we did not ask that we should know?

> Answer:
```

## Rules for the questions

- Up to four options per question, mutually exclusive, recommendation first.
- "I don't know" and "Something else" are always the last two options. A
  document has no question tool to add a free-text field.
- An open question carries your best guess, so the recipient corrects
  instead of writing from nothing.
- Number the questions across the whole document, so a reply can say "3: b".
